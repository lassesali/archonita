================================================================================
1. ARCHITECTURE & TARGET BASELINES
================================================================================

- Desktop Target:
  OpenGL 4.6 Core Profile (#version 460 core).
- Android / Mobile Target:
  OpenGL ES 3.2 (#version 320 es) with precision qualifiers
  (precision highp float;, precision highp int;, precision highp sampler2D;)
  injected by ShaderManager::buildPreprocessedSource().
- Web / Emscripten Target:
  CMakeLists.txt pairs upstream/development SDL 2 (-sUSE_SDL=2) with WebGL 2
  flags (-sMIN_WEBGL_VERSION=2, -sMAX_WEBGL_VERSION=2, replacing
  LEGACY_GL_EMULATION). ShaderManager::compileShader selects ES shader
  profiles for TORQUE_OS_EMSCRIPTEN (WebGL 2 GL attributes in
  EmscriptenOGLVideo.cpp remain a follow-up item; see Section 3.A.4).
- Direct State Access Abstraction (GLDSA):
  4.5+ DSA calls are wrapped behind GLDSA::* in engine/source/graphics/glDSA.h
  and glDSA.cc so core engine code compiles and runs cleanly against OpenGL 4.6
  Core, OpenGL ES 3.2, and future ANGLE/Vulkan or macOS fallback paths.
- VAO-Backed Programmable Pipeline & CPU Matrix Stacks:
  Fixed-function immediate mode, client arrays, matrix stacks, GL_ALPHA_TEST,
  and glClipPlane calls are replaced by VAO/VBO/IBO streaming draws in
  ShaderManager and CPU matrix stacks in dglMatrix.cc.
- Phase Scope:
  Phase 1 strictly replaces the internal fixed-function rendering pipeline;
  custom ShaderAsset TAML types are deferred to Phase 2.
